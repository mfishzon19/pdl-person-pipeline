# PDL Canonical Value Tables — Link Inventory

The complete set of **Canonical Field Values** pages from the PDL documentation
("Data Standardization → Canonical Field Values"), sorted by whether each table
applies to OUR PDL data bundle (Person + Company Enrichment Premium).

This document is a **link inventory** — not a design spec. For the modeling
decision (loader-discovered ref tables; no seeded layer), see [ADR-0011](../decisions/0011-loader-discovered-ref-tables.md).

URLs follow the pattern `https://docs.peopledatalabs.com/docs/<slug>`.

## B. Not in our PDL data bundle

PDL publishes the canonical list but we don't receive the data: excluded by our bundle, never emitted on our tier, or intentionally dropped from our schema.

| Table | URL | Reason out |
|---|---|---|
| Relationship Statuses | https://docs.peopledatalabs.com/docs/relationship_status | Parent Subsidiary Details extension only — not in our PDL contract |
| Relationship Catalysts | https://docs.peopledatalabs.com/docs/relationship_catalysts | Parent Subsidiary Details extension only |
| Email Types | https://docs.peopledatalabs.com/docs/email-types | `emails[]`/`phones[]` dropped from staging per [doc 13 §6.1](13_person.md) (PII exclusion) |
| Profile Networks | https://docs.peopledatalabs.com/docs/profile-networks | V11 dropped `pdl_person_profiles_parsed` |
| Remote Work Policies | https://docs.peopledatalabs.com/docs/remote-work-policies | Not emitted in our bundle |
| Language Names | https://docs.peopledatalabs.com/docs/language-names | PDL does not emit `languages[]` on our tier |
| Salary Periods | https://docs.peopledatalabs.com/docs/salary-periods | No salary-period / pay-frequency data in our bundle |
| Confidence Levels | https://docs.peopledatalabs.com/docs/confidence-levels | We use `likelihood` (integer 0-10), not the PDL confidence-level enum |
| Currency Codes | https://docs.peopledatalabs.com/docs/currency-codes | Funding amounts emitted as bare numbers (USD-assumed) |
